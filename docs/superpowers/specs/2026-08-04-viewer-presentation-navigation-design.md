# 3DGS 查看器演示导航与坐标显示设计

## 目标

修复结果查看器的四个交互问题：全屏演示无法退出、键盘左右方向键无效、无法完成
完整 360° 环视，以及 XYZ 坐标轴/坐标信息不明显。保持左侧 01–06 主导航、深色
浮层 Inspector、现有 ViewerProject 状态模型和 q3dviewer 集成边界不变。

## 根因证据

- `ViewerBindings` 只把事件过滤器安装在主窗口，并且只处理 `watched is window`。
  焦点落在 QOpenGLWidget、工具栏或其它子控件时，`Esc` 和方向键不会进入该逻辑。
- 左右方向键当前只调用 `ViewerPlayback.step_backward/step_forward`；没有时间轴镜头
  时帧数为 0，所以调用没有可见效果。
- q3dviewer 已有 Euler 旋转能力，但应用层没有把它暴露为全局键盘环视或明确的自动
  环视操作；用户只能依赖鼠标拖动。
- `SceneOverlayItem` 只绘制三条彩色线，没有绘制 X/Y/Z 文本标签；相机位置/目标数值
  由 `show_camera_info` 控制且默认隐藏。

## 设计

### 1. 全屏状态与全局键盘事件

`ViewerBindings` 在 QApplication 级别注册事件过滤器，并只接受主窗口及其后代控件的
键盘事件。`Esc` 在演示模式下优先退出，不受当前焦点控件影响；演示按钮同时作为可见
的进入/退出开关，按钮文字和 tooltip 随状态切换。退出时恢复进入前的 sidebar、status
bar 和原始窗口全屏状态。

普通文本输入控件仍保留方向键行为；3D 查看器、演示模式和非文本控件才交给查看器
导航逻辑，避免破坏输入框编辑。

### 2. 方向键与环视语义

- 演示模式：Left/Right 每次执行固定角度水平环视，Up/Down 执行固定角度俯仰，并
  消费事件，保证焦点在任何查看器子控件时都可用。
- 普通模式且存在时间轴：Left/Right 保持时间轴逐帧步进兼容行为。
- 普通模式没有时间轴：Left/Right/Up/Down 退化为相同的相机环视操作。

适配器提供 `orbit(delta_yaw, delta_pitch)`，以当前场景中心和轨道距离为基准改变
相机姿态；水平角允许连续累积并跨越 360°，俯仰限制在接近 ±90° 的安全范围，避免
翻转和数值奇异。每次相机改变都刷新当前相机信息，交互结束时再提交项目脏状态。

### 3. 自动全景环视

ViewerToolbar 增加一个可切换的“环视”按钮。绑定层使用 33 ms QTimer 驱动适配器以
固定角速度水平旋转；再次点击、停止漫游、切换页面、开始导出、加载新 PLY 或关闭应用
都会停止计时器。环视过程中不逐帧写 sidecar；停止时同步一次当前相机姿态，避免项目
状态被高频更新污染。

### 4. XYZ 坐标可视化

`SceneOverlayItem` 保留红/绿/蓝三条世界轴，并为端点增加 `X`、`Y`、`Z` 标签。标签
使用世界坐标投影到视口后由 Qt Painter 绘制，禁用深度遮挡但只在端点位于相机前方时
显示；标签颜色与轴线一致，使用深色半透明底提升对 Gaussian 背景的可读性。

进入演示模式时强制显示紧凑的相机位置/观察目标 XYZ 信息；退出时恢复用户原来的
`show_camera_info` 设置。Inspector 中原有的数值编辑控件继续保留，三类信息分别承担
场景方向识别、演示读数和精确编辑职责。

## 错误处理与边界

- 未加载模型时，方向键和环视按钮不执行且给出状态栏提示，不启动空场景计时器。
- 任一 adapter 环视调用失败时停止自动环视并显示错误，不吞掉异常状态。
- 全屏进入失败时清理已保存的 presentation state，避免后续 Esc 处于错误状态。
- 环视定时器在 `shutdown()` 前停止，确保不会在 adapter release 后继续访问 OpenGL widget。

## 验收标准

1. 焦点在 3D 视图或工具栏时按 Esc 能退出全屏；点击演示按钮也能退出并恢复窗口状态。
2. 演示模式方向键可见地改变相机；有时间轴时普通模式方向键仍能逐帧步进。
3. 手动方向键和“环视”按钮都能完成超过一整圈的水平视角变化，不在 360°处锁死。
4. 开启坐标轴后能看见带 X/Y/Z 标签的彩色轴；演示模式能看见相机/目标 XYZ 数值。
5. 新增失败测试先在旧实现失败，查看器测试与全量测试通过。
