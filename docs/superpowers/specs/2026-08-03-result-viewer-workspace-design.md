# 结果查看工作区视觉与布局设计

## 目标

把 `03 结果查看` 从带有页面标题、说明和来源卡片的普通表单页，收敛成以
3D 展示为核心的工作区。左侧 01–06 全局主导航保持不变；结果页内部只保留
展示区、查看器工具栏、时间轴和按需出现的参数控件。

## 已确认的用户决策

- 保留左侧 01–06 主导航。
- 进入结果查看后不展示“工作流 03 · 查看与检查”“结果查看”以及重复的
  页面说明文字。
- 结果来源卡片不再占用展示区上方空间；打开本地 PLY 通过空状态或查看器
  工具栏完成。
- 参数面板采用 Supersplat 风格的右侧悬浮面板，默认折叠。
- 参数面板展开或收起不改变 OpenGL 展示区的布局尺寸。
- 控件不使用整片白色背景，统一使用当前工作站的深色 viewer chrome。

## 目标平台与边界

- 主应用：PySide6 Qt Widgets，使用现有 Fusion/QSS 主题和设计 token。
- 主设计尺寸：1600×900；保留现有应用最小窗口约束 1024×680。
- 输入：鼠标和键盘；所有浮层操作必须有可见焦点和可访问名称。
- 本次只调整结果查看页面的布局、状态展示和视觉主题，不修改 Gaussian
  渲染器、ViewerProject 数据模型、现有信号名称或业务控制器协议。

### 页面壳

`ResultViewerPage` 隐藏 `BasePage` 的页面级标题区域，并将内容边距收敛到
viewer 工作区。左侧主导航仍由 `MainWindow` 管理，页面索引和导航文本不变。

加载完成后：

- 隐藏页面标题、eyebrow、描述、结果目录/源码信息卡。
- 不展示常驻的“已加载 X 个 Gaussian”成功横幅。
- 视口、工具栏、时间轴和浮层参数面板填充主内容区。

未加载时：

- 同样不显示页面标题和来源卡片。
- 视口中显示简洁空状态，提供“选择本地 PLY”操作。
- 打开或加载失败等真实状态仍可用紧凑状态提示表达，但不恢复旧的表单卡片。

### 展示区与工具栏

- 展示区是唯一的主视觉区域，保持当前深色背景。
- 顶部工具栏保留打开、重置、适配、保存、显示模式、质量、播放、时间轴、
  演示和导出等已有操作；工具栏使用深色 raised surface，不再使用白色控件。
- 参数按钮继续保留，作为键盘和工具栏入口；它与右侧参数把手控制同一个
  `ViewerInspector` 展开状态。
- 时间轴继续复用现有组件，位于展示区下方并按需显示；它不参与参数面板的
  横向布局计算。

## 右侧参数浮层

### 结构与状态

现有 `QSplitter` 横向分栏替换为展示区内的 overlay host：OpenGL 视口占满
host，Inspector 作为同一 host 内靠右的浮层子项。浮层带有外边距和边界，展开
时覆盖视口最右侧，不挤压或重新计算视口尺寸。

- 默认状态：折叠，仅保留约 44px 宽的右侧把手。
- 展开状态：面板宽度约 320px，最大不超过展示区宽度的 40%。
- 面板顶部显示“参数”和明确的折叠按钮；折叠状态按钮仍可通过 Tab 聚焦。
- 折叠/展开使用 200–300ms 的功能性过渡；若当前 Qt 运行环境不适合动画，
  允许瞬时切换，不能影响渲染线程。
- 面板滚动只发生在 Inspector 内容区域，浮层外部不出现第二个页面滚动条。

### 控件分组

保持现有四组：`视图`、`相机`、`外观`、`渲染`。第一组默认展开，其余分组
保持现有折叠行为。此次不改变控件对应的设置对象和信号，只调整容器层级、
间距、尺寸和颜色。

## 视觉语言与 token

结果查看工作区使用语义化的深色 token：

- 工作区背景：现有 `dark_background`。
- 浮层表面：比工作区略亮的深蓝灰实底或高不透明度深色表面，确保 OpenGL
  内容不会透过文字产生干扰。
- 控件表面：`dark_surface_raised`；悬停/选中使用 `dark_surface_selected`。
- 文本：主文本使用 `dark_text`，标签和辅助文本使用 `dark_text_muted`。
- 强调：现有 `dark_interactive` 青绿色，仅用于主操作、焦点和选中状态。
- 边框：现有 `dark_border`；焦点继续使用 `dark_focus`。

必须覆盖的 Qt 控件包括 `QPushButton`、`QToolButton`、`QComboBox`、
`QAbstractItemView`、`QLineEdit`、`QSpinBox`、`QDoubleSpinBox`、
`QCheckBox`、`QScrollArea` 及其内容容器，避免只给部分控件设深色而留下
白色输入框或下拉菜单。

## 响应式与可访问性

- 1024×680 下不使用 QSplitter 挤压视口；Inspector 折叠时只占把手宽度，
  展开时覆盖右侧区域。
- 保留现有 16px 正文基准、可见焦点边框和至少 40px 的主要控件高度。
- 面板折叠按钮、工具栏参数按钮、空状态打开按钮均设置明确的
  `AccessibleName` 和 tooltip。
- Tab 顺序按工具栏 → 参数把手/面板 → 时间轴的视觉顺序排列；Escape 可以
  退出演示模式，浮层不存在键盘陷阱。
- 颜色不作为唯一状态提示；加载失败仍需保留文字和状态符号。

## 实现文件边界

- `src/camera_system_app/ui/pages/base.py`：暴露页面标题可见性或等价的
  页面壳控制，不改变其他页面默认行为。
- `src/camera_system_app/ui/pages/result_viewer.py`：移除结果页内部多余卡片，
  建立 viewer overlay host，管理 Inspector 的折叠状态与加载状态。
- `src/camera_system_app/ui/widgets/viewer_inspector.py`：增加浮层标题/折叠把手，
  保持既有设置控件、信号和四组折叠内容。
- `src/camera_system_app/ui/design_tokens.py`：补充必要的语义化 viewer surface
  token，不直接散落新的颜色字面量。
- `src/camera_system_app/ui/theme.py`：为 viewer chrome、浮层和所有输入控件
  提供完整深色 QSS，包括下拉列表和焦点态。
- `tests/app_shell/test_viewer_ui.py`：覆盖页面壳隐藏、浮层默认折叠、展开不改
  视口尺寸、深色对象名样式入口和已有信号行为。

## 验收标准

1. 左侧 01–06 主导航仍可见且导航索引不变。
2. 加载结果后，页面内不再出现工作流 eyebrow、结果页标题、说明和来源卡片。
3. 结果页主内容由展示区、工具栏、时间轴和按需参数控件组成。
4. Inspector 默认折叠成右侧把手；展开后覆盖右侧而不改变视口宽高。
5. Inspector、工具栏、下拉菜单和输入控件均为深色层级，不出现整片白色控件。
6. 现有显示、外观、渲染、相机、书签、时间轴和工具栏信号测试继续通过。
7. 在现有最小窗口和 offscreen Qt 测试下无布局异常、控件不可达或异常白底。
