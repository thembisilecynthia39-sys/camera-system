# Scripts

- `setup/`: host and camera setup helpers.
- `diagnostics/`: USB, V4L2, OpenCV, PyAV, and pipeline probes.
- `jetson/`: Jetson stack validation and end-to-end smoke tests.
- `services/`: standalone subprocess services used by the application.
- `testing/`: manual integration tests that require hardware or a GUI.
- `experiments/`: exploratory code that is not part of the production package.
- `visualization/`: deterministic UI rendering and screenshot helpers.

Run scripts from the repository root so relative project paths remain predictable.
